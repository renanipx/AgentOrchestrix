# 🤖 AgentOrchestrix

**AgentOrchestrix** is a multi-agent Markdown-based protocol designed to guide AI assistants in IDE environments (such as Antigravity, Cursor, Windsurf) to work in a transparent, robust, self-correcting, and auditable manner.

By structuring AI execution into **well-defined phases** with input and output contracts (CONTRACTS) and strict phase-specific rules (RULES), the protocol reduces hallucinations, mitigates self-praise bias, and ensures high quality in the delivered code.

---

## 🚀 How to Use

In your IDE's chat, invoke the protocol commands:

* **`orchestrate: <goal>`**: Executes the complete development cycle (Phase 0 through Phase 6 and completion).
* **`plan: <goal>`**: Executes the interview, planning, and architecture (Phases 0 to 2), generating a consolidated planning summary.
* **`analyze: <path>`**: Maps an existing codebase (brownfield project) before planning modifications.
* **`continue-run: runs/run-XXX`**: Resumes an interrupted execution consistently using the persisted state.
* **`validate-run: runs/run-XXX`**: Re-validates a run starting from Phase 4 (Validator) using logs and tests.

---

## 🗺️ The Phase Cycle

The protocol operates through the following phases, managing progress in the `runs/run-XXX/state.json` file:

```mermaid
flowchart TD
    F0["0_interview<br/>(Interview)"] --> F1["1_planner<br/>(Requirements)"]
    F1 --> F2["2_architect<br/>(Architecture)"]
    F2 --> F3["3_builder<br/>(Coding)"]
    F3 --> F4["4_validator<br/>(Tests & Lint)"]
    F4 --> F5["5_reviewer<br/>(Clean Code)"]
    F5 --> F6["6_critic<br/>(Risk Review)"]
    F6 -->|No high risks| DONE["completed<br/>(Completed)"]
    F6 -->|HIGH risk| WAIT["waiting_for_user<br/>(Waiting)"]
    WAIT -->|Refactor| F2
    WAIT -->|Approve and Complete| DONE
    F4 -->|Failure (Rollback)| F3
    F5 -->|Architecture Failure (Rollback)| F2
    F5 -->|Code Failure (Rollback)| F3
```

## ⚙️ Setup

1. Copy the entire contents of this repository to the root of your workspace.
2. Add the contents of the [AGENTS.md](AGENTS.md) file into your IDE assistant's custom instructions settings (System Prompts).
3. Start your first orchestration with the command `orchestrate: <your goal>`.

For advanced details on agent behavior, see [AGENTS.md](AGENTS.md).
